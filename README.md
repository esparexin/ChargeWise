# ChargeWise

ChargeWise is a privacy-first, offline-first battery-care assistant for macOS and iOS. It helps people make informed charging and usage decisions to reduce avoidable battery wear while preserving everyday convenience.

## Product principles
- Local-first: no account, backend, cloud sync, analytics, or advertising in V1.
- Honest telemetry: show only measurements available through supported platform APIs; never fabricate or infer unavailable metrics.
- Practical advice: recommendations explain what is happening, what to do, and why.
- Shared logic: battery-care rules are centralized and reused across platforms.
- User control: history and manually entered values can be reviewed, edited, and deleted.

## Platforms
- macOS: battery/power source monitoring, menu-bar experience, dashboard, settings, notifications.
- iOS: battery level/state monitoring, dashboard, educational guidance, manual health/cycle details where supported.

## Current status
Project is in **Phase 0 — Preparation**. Application implementation has not started. Platform capabilities, minimum OS targets, architecture, requirements, and QA gates must be reviewed before implementation begins.
